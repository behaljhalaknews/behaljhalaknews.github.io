📰 नई खबर प्रकाशित करें

अब JSON कॉपी करने की जरूरत नहीं है। खबर की जानकारी भरें, फोटो चुनें और Publish करें। फोटो चुनी गई तो वह उसी खबर से अपने-आप जुड़ जाएगी।

मोबाइल से सीधे MP4/WEBM वीडियो चुनें। वीडियो Supabase के सुरक्षित news-videos bucket में जाएगा। YouTube लिंक भी पुराने तरीके से काम करेगा।

मोबाइल में Gallery/Photos से एक या कई फोटो चुन सकते हैं।

खोज बॉक्स में शीर्षक का कोई शब्द लिखें। सूची अपने-आप छोटी हो जाएगी। फिर संबंधित खबर चुनें।

अभी कोई खबर तैयार नहीं है।
यदि Publish Workflow उपलब्ध न हो

नीचे वाला विकल्प केवल fallback है। सामान्य स्थिति में इसे इस्तेमाल नहीं करना है।

👥 Subscriber Manager

यह सेक्शन केवल Admin Login के बाद दिखाई देता है। यहां Subscriber की Email, Registration Date और Status देखे जा सकते हैं। Subscriber को Admin Manager का कोई access नहीं मिलता।

📝 प्रकाशित खबर की श्रेणी बदलें

अगर किसी प्रकाशित खबर की श्रेणी गलती से गलत चुन गई है, तो पूरी खबर दोबारा लिखे बिना केवल उसकी श्रेणी बदली जा सकती है। शीर्षक, फोटो, तारीख और खबर का बाकी कंटेंट सुरक्षित रहेगा।

खबर चुनें।
सुरक्षित Publish चरण

Category Change Package Clipboard में कॉपी हो गया है। नीचे बटन दबाएँ और GitHub Actions में package पेस्ट करके Run करें।

🗑️ प्रकाशित खबर हटाएँ

जिस खबर को हटाना है उसे चुनें। हटाने से वेबसाइट की खबर और उसकी HTML page हटेगी। Supabase में पुरानी फोटो अपने-आप delete नहीं होगी।

खबर चुनें।
सुरक्षित Remove चरण

Delete ID कॉपी हो गई है। नीचे बटन दबाएँ और GitHub Actions में केवल यही ID पेस्ट करके Run करें। Browser में GitHub token नहीं रखा गया है।

📷 मौजूदा खबर की फोटो बदलें

📢 Direct Advertisement Manager

यह AdSense से अलग Sponsor/Direct Ads सिस्टम है। TOP विज्ञापन वेबसाइट के ऊपर और NEWS विज्ञापन खबरों के अंदर दिखेंगे। तारीख खत्म होने पर विज्ञापन अपने-आप बंद हो जाएगा।

एक से अधिक खबरें चुन सकते हैं।
