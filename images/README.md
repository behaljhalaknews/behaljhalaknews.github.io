# बहल झलक — Images

इस फ़ोल्डर में वेबसाइट की समाचार तस्वीरें रखी जा सकती हैं।

## Recommended format
- JPG या WebP
- सामान्य अनुपात: 16:9
- Homepage hero के लिए लगभग 1200×675 px
- News cards के लिए लगभग 800×450 px
- फ़ाइल नाम: छोटे अंग्रेज़ी अक्षर, अंक और hyphen, जैसे `bahal-tanker-fire-2026-09-28.jpg`

## News data में image path
यदि फोटो इसी repository में है, तो news object में उदाहरण:
`"image": "./images/bahal-tanker-fire-2026-09-28.jpg"`

## महत्वपूर्ण
फोटो तभी प्रकाशित करें जब उसके उपयोग का अधिकार/अनुमति आपके पास हो या वह आपके लिए उपयोग योग्य स्रोत से हो। किसी दूसरे समाचार संगठन की फोटो को केवल कॉपी करके प्रकाशित न करें।
