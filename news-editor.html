📷 फोटो GitHub में डालने का सबसे आसान तरीका
  1. GitHub में अपनी repository खोलें: behaljhalaknews.github.io
  2. images folder खोलें। अगर folder नहीं है, तो पहले Add file → Create new file से images/README.md बना दें।
  3. Add file → Upload files दबाएँ और अपने मोबाइल से फोटो चुनें।
  4. फोटो का नाम आसान रखें, जैसे bahal-market-fire-2026-09-28.jpg। spaces और बहुत लंबे नाम न रखें।
  5. नीचे Commit changes दबाएँ। फोटो अब GitHub के images folder में आ जाएगी।
  6. अब News Editor में फोटो का सही path ऐसे लिखें: ./images/bahal-market-fire-2026-09-28.jpg
  7. Preview में फोटो दिखाई दे तो path सही है। फिर Code तैयार करें दबाएँ।

याद रखें: ./images/ के बाद GitHub में रखी गई फोटो का exact filename ही लिखना है। बड़े-छोटे अक्षर भी बिल्कुल वही रखें।

⚙️ GitHub में Publish News खोलें
⚙️ GitHub Actions से Publish करने के आसान स्टेप
  1. Code Copy करें — ऊपर तैयार हुआ पूरा news object copy करें।
  2. Publish News बटन दबाएँ — GitHub Actions वाला पेज खुलेगा।
  3. वहाँ Run workflow दबाएँ।
  4. Form में Title, Category, Location, Date, Image, Excerpt और Content भरें।
  5. Featured केवल तभी ON करें जब यह खबर Homepage की मुख्य खबर बनानी हो।
  6. नीचे Run workflow दबाएँ और कुछ समय इंतज़ार करें।
  7. Workflow पूरा होने के बाद वेबसाइट खोलकर खबर देखें। GitHub Pages को update होने में थोड़ा समय लग सकता है।

महत्वपूर्ण: News Editor अभी सुरक्षित तैयारी/Preview के लिए है; GitHub Actions में खबर की जानकारी दोबारा भरनी पड़ती है। GitHub password या personal access token इस वेबसाइट में कभी न डालें।

Publish checklist
  • तथ्य, नाम, स्थान और समय verify करें।
  • फोटो के उपयोग का अधिकार सुनिश्चित करें।
  • फोटो GitHub के images folder में upload करने के बाद path रखें: ./images/filename.jpg
  • Generated object को workflow के जरिए publish करें।
